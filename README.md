# Fixer's Cut

ヨミハマの新人フィクサーとして、契約・義体化・情報購入・派遣を管理するブラウザーゲームです。外部サーバーやビルドは不要です。UTF-8の静的HTTPサーバーで `index.html` を開いてください。保存先はブラウザーのlocalStorageです。

## 現在の仕様

- 現場3人・支援2人・ネット1人。能力＋技能＋d10で判定。10は追加、1は減算。HP半分未満は判定−2、防具は貫通時に摩耗、HP0は死亡セーブ。
- 歩合は本人に分け前、専属はフィクサーに分け前が入り毎夜手当が必要。仲介料20%。家賃・借金・義体ローン・救急会費・設備維持費を夜ごとに精算。3夜連続赤字で廃業。
- 評判による紹介依頼でランクを上げ、全6章のブラックボックスの物語を進めます。
  - 第1章 引き継ぎ → 第2章 鍵を探す → **分岐**（ミツカネ・ヴェルデ・ハクロウのどれと組むか）→ 第3章 積み荷（3通り）→ 第4章 沈む名前 → 第5章 調整役（3通り）→ 第6章 夜明け。
  - 組んだ社はヒート−30、残りの二社は+10。分岐ごとにメイン依頼の標的・必要なロール・物語が変わり、第4章と第6章にも組んだ社ごとの段落が入ります。分岐を選ぶまで夜は明けません。
  - 第4章のメイン依頼は、章に入ってから2夜たつと依頼盤に出ます（手がかりを洗う期間）。
  - 分岐を入れる前の保存データは、元の筋書きと同じ依頼が並ぶハクロウの分岐として続きます。企業3社のヒート100で防衛戦。
- 派遣中の現場重傷、警報、死亡セーブ生存で最大2回、続行／撤退を選択。敵の攻撃直後に中断でき、続行時に済んだ判定は繰り返しません。撤退は報酬なし・失敗扱い、固定費は通常どおり。2夜依頼は実際の夜ごとに判定。判断待ちは保存・再開できます。
- 屋台街・港湾倉庫・企業区画上層。地区状況は3夜、ニュース17種は1夜。毎夜「噂」が1つ流れ、白蛇会との関係・ヒート・死者・章に応じた噂も混ざります。補正は判定と見積もりで共通。運搬の報酬補正は派遣時に固定されます。
- 依頼は通常18種（ランク1：9、ランク2：6、ランク3：3）。記憶テープの奪還、白蛇会の看板の乗っ取り、逃げたAIの捕獲、差し押さえ義体の奪還、記憶銀行からの人格の引き出しなど。
- 幕間7種：初めての義体、初めての死者、人間性15以下、ランク2、ヒート80、夜12、箱を開けた後。条件を満たした夜明けに一度だけ流れる。結末では、生き残ったランナーのその後が一行ずつ添えられる。
- 白蛇会との関係は−100〜100。+30以上で情報割引・路上候補増、−30以下で敵増援と3夜ごとの嫌がらせ。防犯設備で嫌がらせを防止。
- 隠れ家の設備8種（2,500〜9,000cr、一部は2段階）：訓練室、武器庫、医療室、ネット設備、車庫、情報屋の端末、防犯システム、仮眠室。「装備・設備」タブで購入。維持費は夜明けの見込みにも表示。
- 成長：派遣中の判定に使った技能に経験がたまり、素の技能 n→n+1 は n+4 回で上がる（上限10）。訓練室があれば待機中も本業の技能が伸びる。技能カードの細い線が次の上昇までの進み具合。
- 装備21種（武器・防具・道具を1つずつ、700〜5,000cr）。人間性を削らずに技能や防具を足す。専属はフィクサー、歩合は本人の手持ちで払い、歩合は自分でも買う。入れ替えは半額で下取り。徹甲ライフルはテックなしで装甲兵の弱点を突く。テーザーは過剰な暴力にならず、ICE遮断フードは黒ICEの逆流を半減する。
- 義体31種を6つの部位（神経系・頭脳・感覚と発声・腕と手・体表・内臓）に分け、闇医者で部位ごとに絞り込める。系統ごとに上位モデル（Mk.II・Mk.III）があり、入れると下位モデルと入れ替わって人間性は差の分だけ減る。下位モデルへは戻せない。基本モデルの人間性コストは下げ、上位モデルほど重い。ニューラル防壁は黒ICEと敵ネットランナーの攻撃を無効化、人工心臓は死亡セーブ+2（弐は+3）。どれも肖像に重ねて描かれる。
- 精算の「効いたもの」に、技能・装備・義体・設備が失敗を成功に変えた回数を表示。通信の計算式も補正の出どころ（〈装備+2〉、＋逃げ足 3 など）を分けて表示。ロール技能はこれまでに効いた回数をランナーカードに残す。
- 成功の見込みに、判定ごとの成功率と担当、失敗するときの主な原因を表示。
- 右上の「説明」ボタンで初めての人向けの説明（チュートリアル、凡例、各画面の解説、隠れ家のヒート欄）をまとめて隠せる。設定はブラウザーに保存。
- ランク1の敵はDV17・攻撃16・3d6+2、ランク1依頼の判定DVは+2。初期の2人編成で70〜90%、3人のそろった編成でほぼ確実。
- 装甲兵（テックで弱点攻撃）、敵ネットランナー（ICE攻撃）、狙撃手（知覚で先制阻止）、群れ。情報購入で敵種を開示。
- 雇えるランナーには出自ごとの素性が1行つく。
- まれに資質つきのランナーが現れる（候補1人ごとに、超希少の異常適合3%・希少の適合体質10%・希少の天才肌8%）。異常適合は人間性の上限150で義体の人間性コストが半分、適合体質は上限+30でコスト3/4、天才肌は技能の伸びが早い。資質つきは分け前の希望と手当が高い（1.2〜1.8倍）。ヨルは適合体質。
- 物語つきは5人（カゲロウ・ヨル・ハルカ・シグレ・ミコト）。ヨル・ハルカ・シグレ・ミコトは夜3以降、35%の夜にスカウトへ現れる。専属かつ忠誠70以上で個人依頼。シグレの依頼はクロガネとの関係が下がる。本人参加が必須。成功でロール技能と別の専用技能、失敗は忠誠−30、期限まで受けなければ離脱。発生時に物語を表示。
- クロガネ・ネオンの2人が依頼を横取りし、ランナーを引き抜きます。妨害依頼と関係・横取り・引き抜き状況を表示。
- 保存データが読み込めないときは消さずに残し、タイトルで知らせる（最新のファイルで読み込み直す・保存データを書き出す）。新しく始めるときは直前の保存データを `fixers-cut-save-v1-backup` に1つ残す。画面の描画が止まったときは、白い画面ではなく復旧の画面を出す。GitHub Pagesはファイルを10分キャッシュするため、更新直後は古いファイルが混ざることがある。
- 最後の派遣編成を「いつもの面子」で復元。欠員・重体・療養・派遣中は除外して通知。通信速度4段階と合成効果音（初期オフ）は保存。一括表示・一瞬・動きを減らす設定では音が集中しません。

## 構成

- `js/data.js`：依頼・ロール・義体・装備・物語・章の表。依頼の判定DV、交戦ごとの敵種と敵DV（`C(数, 名前, 敵種, 敵DV)`）、地区はここに書かれた値がそのまま使われます。
- `js/engine.js`：状態、判定、夜の進行、精算、章の進行（条件の種類 `REQS`）。敵の基準値 `RANK_ENEMY` と編成枠 `LANE_MAX` もここ。
- `js/world.js`：地区・ニュース・設備・関係・ライバルなど、夜ごとに変わるルール。静的な表は書き換えません。
- 章は `CHAPTERS` に章のキーで定義し、保存データもキーを持ちます。章を足すときは、`CHAPTERS` に1件足して前の章の `next` をつなぎ、メイン依頼があれば `CAMPAIGN_JOBS` に `campaign: '章のキー'` で足します。表示の番号（`no`）は分岐で同じ番号を共有してかまいません。分岐は、メイン依頼の成功後に出す `choice` と、手を組んだ社で次の章を決める `next: { ally: {...} }` で書きます。番号で章を持っていた古い保存データと、分岐前のキー（`cargo`・`coordinator`）は、読み込み時に変換されます。
- `js/comfort.js`：いつもの面子と効果音。`ui.js` より先に読み込みます。
- `js/art.js`・`js/ui.js`：描画と操作。

## 検証

Node.js 24で実行します。依存パッケージはありません。

```powershell
node --test --test-isolation=none tests/comfort.test.cjs tests/mission.test.cjs tests/world.test.cjs tests/growth.test.cjs tests/content.test.cjs tests/chapters.test.cjs
node tests/balance.cjs
```

49件のテストで保存データの保護、義体の系統と換装・資質、3つの分岐それぞれの全章の通し・章の表の整合・古い保存データの変換、新しい義体・装備・物語つきランナー・幕間・噂、装備・技能の成長・効いたものの集計・見込みの内訳・段階つき設備・訓練室に加え、中断再開・保存復元・再抽選防止・精算・2夜依頼・設備・個人依頼・関係・ニュース・編成・音を検証します。難易度はseed=20261102、能力とロール技能の中間値、義体／技能特典なし、必須ロール＋無傷のソロ2人、情報購入済み、地区／ニュース補正なしを基準に各ルート5,000回。通常ランク2の12ルートは71.7〜82.4%（70〜85%をassert）。実際の編成・状況によって確率は変わります。

`tools/smoke.html` は購入と必ず発生する警報を試すローカル確認画面です。保存を無効にしているため通常のセーブを書き換えません。ブラウザーで購入→派遣→警報→一瞬／すべて表示→撤退→失敗精算を確認済み。390px幅の判断画面は `tests/retreat-mobile.jpg` に保存しています。
